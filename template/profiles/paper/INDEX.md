# Memory index

Use this map to retrieve narrowly; it is not a duplicate project database.

| Need | Read |
|---|---|
| Paper goal, venue, claims | `.ai/knowledge/PROJECT.md` |
| Research questions and hypotheses | `.ai/knowledge/RESEARCH_QUESTIONS.md` |
| Methods and model choices | `.ai/knowledge/METHODS.md` |
| Experiment ledger and results | `.ai/knowledge/EXPERIMENTS.md` |
| Compute/toolchain environment | `.ai/knowledge/ENVIRONMENT.md` |
| Accepted or rejected decisions | `.ai/decisions/` |
| Current work | `.ai/changes/<active-change>/` named by `NOW.md` |
| Historical changes/experiments | `.ai/archive/` (never default) |

Verify links and claims against source, data versions, tests, branch, and commit.
