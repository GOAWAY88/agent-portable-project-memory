# Project

Agent-Portable Project Memory Framework is an open-source, vendor-neutral protocol and template that keeps a software project's durable context in Git-tracked repository files so coding agents can switch without private chat history.

V0.2 strengthens memory integrity through structural validation, provenance checks, negative tests, and CI. V0.3 adds init-time project profiles (software default, paper overlay) with a declarative `.ai/profile.md` manifest, keeping the protocol domain-neutral. It still deliberately uses portable Markdown plus shell helpers, not a database or cloud service.
