# Decisions

Store one durable decision per file, named `ADR-NNNN-short-title.md`, using `template/.ai/decisions/ADR-TEMPLATE.md`. Status values are `proposed`, `accepted`, `rejected`, `deprecated`, and `superseded`; an accepted ADR must name non-empty evidence.

| ADR | Status | Decision |
|---|---|---|
| [`ADR-0001-apmf-abbreviation`](ADR-0001-apmf-abbreviation.md) | accepted | Use **APMF** as the canonical project abbreviation, with a legacy-marker compatibility window in `init.sh` |
