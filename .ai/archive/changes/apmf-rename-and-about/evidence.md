## Correction (added 2026-09-29 by change `apmf-rename-followup`)

The residual-audit rows above used `grep -rn "APPM" --include="*.md" --include="*.sh"`, which filtered by file extension and therefore **missed `.github/workflows/ci.yml`**, leaving the workflow displayed as `APPM CI` after this change was archived as complete. The audit claim was inaccurate as written; the rows are preserved unchanged because archives are historical records, and this note is appended rather than edited in.

The follow-up change renamed the workflow to `APMF CI` and re-ran the audit as `git grep -n "APPM"` over all tracked files, which cannot miss a file type. Lesson: an allowlist of extensions will always miss the next file type — search everything and filter while interpreting, not while searching. See `.ai/archive/changes/apmf-rename-followup/evidence.md` and the correction recorded in `ADR-0001-apmf-abbreviation`.
