# Proposal: framework-v0.1

## Problem

Project context is lost when work moves between coding agents or sessions.

## Motivation

Create a repository-owned, vendor-neutral memory protocol whose startup context stays small while history remains durable.

## Scope

Define V0.1 architecture, lifecycle, authority/provenance model, template, scripts, and validation tests.

## Non-goals

No database, embeddings, MCP server, cloud backend, automatic summarizer, or full task database.

## Success criteria

The repository contains a usable specification/template, safe initialization and checkpoint helpers, and passing structural tests.
