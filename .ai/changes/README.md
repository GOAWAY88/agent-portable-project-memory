# Changes

Active changes live here, one directory per change, each with `proposal.md`, `design.md`, `tasks.md`, and `evidence.md` (copy from `template/.ai/changes/_template/`). When every task is `DONE`, move the directory to `.ai/archive/changes/`; the validator rejects completed changes that remain active.

This README is tracked so the directory survives in fresh clones even when no change is active (Git does not track empty directories).
