# APMF V0.7 Current Reference Integrity

Status: experimental. V0.7 adds read-only checks for current-memory routes; it does not rewrite historical archives or arbitrary project documentation.

## Scope

`scripts/check-references.sh <project>` scans `NOW.md`, `INDEX.md`, `.ai/knowledge/*.md`, and non-template `.ai/decisions/*.md`. It checks inline-code paths and relative Markdown link destinations that use known repository prefixes. External URLs, placeholders, globs, and historical `.ai/archive/` content are ignored.

Missing `.ai/changes/<name>/...` paths are reported as stale when the corresponding `.ai/archive/changes/<name>/...` path exists. Other missing local routes receive a direct diagnostic. The checker is read-only and reports all failures before exiting non-zero.

`validate.sh` additionally requires any ADR `evidence` front-matter path that names a local route to exist. An accepted ADR still cannot use `[]` as evidence.

## Non-goals

- No automatic route repair or archive rewriting.
- No URL/network checks.
- No recursive validation of historical archives.
- No full Markdown parser or external runtime dependency.
