# APMF V0.5: Lifecycle Closeout

Status: experimental. V0.5 adds a mechanical archive helper; it does not change canonical Markdown, task status vocabularies, provenance rules, or the frozen V0.1-alpha contract.

## Contract

`scripts/archive-change.sh <project> <change>` MUST preflight and reject without writes when:

- the target is not a Git repository or the change name is unsafe;
- `NOW.md` does not name exactly that active change;
- any of the four change artifacts is missing;
- any task status is not `DONE`;
- the archive destination already exists;
- `INDEX.md` lacks a Current work row pointing to the active change.

The helper SHOULD discover exact references to `.ai/changes/<change>/` in current ADR files and include them in the route update. It MUST not rewrite archived files or unrelated paths.

On success it MUST move the complete change directory to `.ai/archive/changes/<change>/`, set NOW's active change to `none`, replace the current-work INDEX row with a NOW pointer, and update exact ADR evidence paths to the archive. It SHOULD run `validate.sh` when the framework helper is available. If any route write or post-update validation fails, it MUST restore the source directory and backed-up route files.

The helper MUST NOT create a Git commit, update semantic summaries, rewrite `updated` or `verified_at_commit`, or infer task completion. The user/agent reviews and commits the resulting tree, then runs provenance closeout as a separate mechanical step.

`--check` MUST perform preflight only and make no writes. A repeated invocation after a successful archive MUST fail clearly because the destination already exists; it is not a silent no-op.
