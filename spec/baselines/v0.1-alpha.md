# Frozen baseline: V0.1-alpha

This file freezes the minimum V0.1-alpha contract that V0.2 integrity checks must not silently remove. It is a compatibility statement, not a generated database or checksum of prose.

## Required entry points

- `AGENTS.md`
- `.ai/NOW.md`
- `.ai/INDEX.md`
- `.ai/knowledge/`
- `.ai/decisions/`
- `.ai/changes/`
- `.ai/archive/`

## Required behavior

- canonical memory is Git-tracked, human-readable Markdown;
- startup reads the small routing layer, not the archive recursively;
- active changes use proposal, design, tasks, and evidence;
- source and executable evidence outrank summaries;
- derived indexes/runtime files are rebuildable and ignored;
- initialization preserves existing `AGENTS.md` and reports conflicts;
- no database, cloud service, LLM, MCP server, or vector store is required.

The compatibility test [`../../tests/test_v01_baseline.sh`](../../tests/test_v01_baseline.sh) runs on every CI build. Changes that intentionally revise this contract require a new versioned baseline and an explicit migration note.
